# Whisker & Wonder 🐾

**Woven with Wonder, Worn with Kindness.**

Whisker & Wonder is a responsive T-shirt shop website featuring animal-inspired designs that celebrate creativity, compassion, and kindness toward stray and rescued animals. It was developed by **Depende Kung Web Yan** for the MMS 142 Assignment 2.

[Visit the live website](https://rfmoreno1.github.io/Whisker-and-Wonder/)

## Website features

- Responsive desktop, tablet, and mobile layouts
- Product catalog and three individual product pages
- Size selection, quantity controls, and automatic subtotal calculation
- Order inquiry and contact forms that prepare email drafts
- Expandable frequently asked questions
- Privacy policy with section navigation
- Accessibility features including descriptive image alt text, keyboard navigation, visible focus indicators, form labels, and reduced-motion support

## Running the website locally

1. Clone or download this repository.
2. Keep the HTML files and their asset folders in the same directory.
3. Open `index.html` in a browser, or serve the project using a local web server.

An internet connection is required to load externally hosted fonts and Bootstrap.
